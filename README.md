# Ramus

Vedi [`SPEC.md`](./SPEC.md) per la specifica di progetto e [`CLAUDE.md`](./CLAUDE.md)
per le convenzioni operative e i comandi (`npm run tauri dev`, `cargo test`, ecc.).
