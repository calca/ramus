# File `LICENSE`

Stato: implementata. Licenza scelta dall'utente: MIT.

## Motivazione

Il repository (`github.com/calca/ramus`, pubblico) non ha un file
`LICENSE`. Su GitHub, senza licenza esplicita, il codice resta sotto
copyright pieno di default: nessun altro può legalmente usarlo,
modificarlo o ridistribuirlo, nemmeno leggendolo su un repo pubblico —
probabilmente non l'intenzione, ma è lo stato di fatto finché non c'è
un file `LICENSE`.

## Domande aperte (bloccanti)

**Quale licenza?** Non è una decisione tecnica, dipende da cosa si
vuole permettere:

- **MIT** — permissiva, minima, la scelta più comune per progetti
  personali/piccoli tool: chiunque può usare/modificare/ridistribuire
  anche commercialmente, unico obbligo mantenere l'avviso di copyright.
- **Apache 2.0** — permissiva come MIT, in più una clausola esplicita
  di licenza brevetti (rilevante solo se preoccupazioni su brevetti
  software, raro per un progetto di queste dimensioni).
- **GPL-3.0** — copyleft: chi ridistribuisce (anche modificato) deve
  farlo con la stessa licenza e codice sorgente incluso. Rilevante se
  si vuole impedire che qualcuno prenda Ramus, lo chiuda e lo rivenda.
- **Nessuna (repository privato)** — se l'intento non è mai stato
  renderlo open source, la risposta è rendere il repo privato, non
  aggiungere una licenza.

## Modifiche

`LICENSE` alla radice, testo MIT standard, copyright "2026 Gianluigi
Calcaterra" (da `git config user.name`). `README.md` guadagna una
sezione "Licenza" con link al file.

Colta l'occasione per sistemare i metadati Cargo/npm che il tema
tocca direttamente (non scope creep: stessa domanda "chi è il
proprietario di questo codice", non un lavoro separato):

- `Cargo.toml` (workspace root): nuovo `[workspace.package]` con
  `license = "MIT"` e `authors = ["Gianluigi Calcaterra"]`.
- `crates/ramus-core/Cargo.toml`, `crates/ramus-mcp/Cargo.toml`,
  `src-tauri/Cargo.toml`: `license.workspace = true` +
  `authors.workspace = true` (stesso pattern già in uso per
  `edition.workspace = true`) invece di duplicare la stringa in ogni
  crate. `src-tauri/Cargo.toml` aveva ancora `authors = ["you"]` e
  `description = "A Tauri App"` — placeholder dello scaffold Tauri mai
  sistemati, corretti qui.
- `package.json`: `"license": "MIT"` (assente prima).

## Fuori scope

Licenze diverse per parti diverse del repository (es. codice vs asset
grafici come la mascotte): complicazione non richiesta, un solo file
`LICENSE` per l'intero repo.

## Verifica

`cargo test`, `cargo clippy --all-targets -D warnings`, `cargo fmt
--check`, `npm run typecheck`, `npm run test` — tutti puliti (i
metadati Cargo/npm non toccano codice). File statico per il resto:
GitHub rileva e mostra `LICENSE` automaticamente nella sidebar del
repo una volta presente in un formato riconosciuto.
