# Content-Security-Policy

Stato: implementata. Prima di otto spec di "production readiness"
(vedi le altre in `specs/release/`), scritte in risposta a "cosa
manca per essere production ready?".

## Motivazione

`src-tauri/tauri.conf.json` ha `"security": { "csp": null }` —
nessuna Content-Security-Policy, il webview può caricare/eseguire
qualunque risorsa da qualunque origine. Tauri considera una CSP
esplicita la base minima per una build di distribuzione: limita cosa
può fare codice iniettato in caso di XSS (superficie reale qui:
`dangerouslySetInnerHTML` in `CommandPalette.tsx` per
`snippet_html`, generato dal core Rust a partire dal contenuto
indicizzato del vault — testo dell'utente, non arbitrario da
internet, ma comunque l'unico punto d'iniezione HTML nell'app).

## Cosa serve

Una CSP che permetta esattamente ciò che l'app usa oggi e nient'altro:

- `default-src 'self'` — tutto il resto eredita da qui.
- `img-src 'self' data:` — i loghi/mascotte sono asset locali
  (`import ... from "../../assets/..."`, bundlati da Vite), nessuna
  immagine remota da nessuna parte.
- `style-src 'self' 'unsafe-inline'` — Tiptap/React inseriscono stili
  inline per certi stati dell'editor; verificare durante
  l'implementazione se è evitabile, altrimenti resta necessario.
- **Nessun** `connect-src` verso host esterni: l'app non fa fetch di
  rete lato frontend (i comandi Tauri sono IPC, non HTTP; Git sync e
  MCP sono processi separati lato Rust, fuori dal webview).
- `script-src 'self'` — nessuno script inline, nessun CDN.

## Modifiche

`src-tauri/tauri.conf.json`, `app.security.csp`: da `null` a

```
default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self'; connect-src 'self'
```

Nessuna modifica al codice applicativo: `cargo check -p ramus` compila
pulito con la nuova policy (la sintassi CSP è validata da Tauri a
build time), JSON valido, nessun'altra regressione nella checklist
standard.

## Domande aperte

Nessuna: la policy proposta è la più restrittiva compatibile con
l'uso reale dell'app oggi, non richiede una scelta di prodotto.

## Fuori scope

- CSP per webview aggiuntivi (non ce ne sono: una sola finestra).
- Permessi Tauri (`capabilities/`) — riguardano quali comandi IPC sono
  invocabili dal frontend, un meccanismo diverso dalla CSP del
  browser; da rivedere in una spec a parte se necessario.
